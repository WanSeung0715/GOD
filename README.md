GOD 팀 프로젝트 내에서 제가 작업한 스크립트만 모아서 올려두었습니다.

Bomb.cs와 Present.cs는 각각 bomb, present 오브젝트에 들어가는 스크립트입니다.

BombsGenerator.cs와 PresentsGenerator.cs는 썰매의 자식객체로 들어가는 각 폭탄,선물 생성기에 들어가는 스크립트입니다.

SantaSpeed.cs는 썰매에 들어가는 스크립트로 속도를 제어합니다.

SuckZone.cs는 집 오브젝트의 위에 있는 구형 콜라이더에 적용되는 스크립트입니다.

ExplosionManager.cs는 굴뚝에 폭탄이 들어왔을 때 집이 폭발하는 효과를 실행하도록 하는 스크립트입니다.
